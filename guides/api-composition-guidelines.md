# Mix API composition

Authoring conventions are maintained in the portable Mix skill references:

- [Styler API policy](../skills/mix/references/styler-api-policy.md): top-level
  constructors, typed shorthand, nullable and directional values.
- [Fluent API](../skills/mix/references/fluent-api.md): chaining and merge semantics.
- [Testing](../skills/mix/references/testing.md): resolution and composition checks.

For design rationale, see [Architecture](../ARCHITECTURE.md).
